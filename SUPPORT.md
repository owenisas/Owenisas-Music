# Owenisas Music Support

**Last updated: 2026-08-12**

Owenisas Music is a local music-library player for iPhone and iPad. It plays audio files that you import from Files and keeps your library, playlists, likes, listening history, and playback settings on your device.

## Import audio

1. Open the **Library** tab.
2. Tap the import button in the top-left corner.
3. Choose one or more audio files using Apple's file picker.

Supported formats include MP3, M4A, AAC, WAV, FLAC, AIFF, and AIF. Import only audio you have the right to use.

## Playback and library controls

- Tap a song to start playback.
- Use Now Playing or Control Center for play, pause, seek, next, and previous controls.
- Long tracks can resume near their saved position.
- Use playlists, likes, shuffle, repeat, crossfade, playback speed, and the sleep timer to customize listening.

## Backup and restore

Open **Home → Settings → Your Data** to export or restore playlists, likes, play history, and saved positions. Audio files are not embedded in the JSON backup; they remain in your app's local Files storage.

## Troubleshooting

If a song does not play:

- confirm that its source file still exists;
- try importing the file again;
- confirm that the file is a supported audio format and is not damaged.

If a backup cannot be restored, confirm it was exported by Owenisas Music and has not been edited into invalid JSON.
